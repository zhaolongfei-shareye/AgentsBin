# AgentsBin 产品项目文档

> 本文件用于项目上下文压缩与交接。覆盖产品矩阵、网站结构、技术架构、多语言、统计后台、部署方式和当前待办。

## 1. 项目总览

AgentsBin 是一个 macOS AI 工具工作室，统一品牌域名：`https://www.agentsbin.com`。

- 定位：本地优先、界面简洁、数据留在用户设备上。
- 当前产品：AgentsBin、Watermark Factory。
- 规划产品：AgentsQS、AgentsTTS。
- 站点语言：8 种（English / 简体中文 / 繁體中文 / 日本語 / 한국어 / Español / Français / Deutsch）。
- 发布渠道：Cloudflare Pages，生产域名 agentsbin.com。

## 9. Watermark Factory 功能清单

- 三步流程：导入 → 识别 → 还原
- 批量导入、逐图预览、选择/取消复选框
- 识别失败：灰色状态 + “图片没有识别水印”提示
- 完成后结果弹窗：导入张数、成功保存张数
- 输出目录：文件夹图标修改、路径显示在进度条上方
- 免费额度：每月 100 张
- 付费方案：$9.9/月无限量；$69.9 永久无限量
- 付费限制：免费仅支持 5MB 内、PNG/JPEG；付费无限制
- 统计入口：顶部图标 + 日历查看每日结果
- 界面语言：8 国语言
